# Ploy Support Docs

> Ploy is an AI-powered web marketing automation platform that helps growth teams build, optimize, and publish high-converting marketing sites. These docs cover the platform, developer tools, setup guides, and troubleshooting.

Ploy includes an in-app AI agent that can build pages, write copy, run research, analyze performance, generate images, operate integrations, and manage deploys through natural conversation. The Ploy CLI provides a standalone terminal interface for workspace, site, content, publishing, and local-development workflows.
